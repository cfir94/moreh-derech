# Codex — הגדרה חד-פעמית (לבעלים)

Codex קורא אוטומטית את `AGENTS.md` שבשורש הריפו, ושם יש הפניה לפרוטוקול. כל מה שצריך:

1. **ב-Codex (chatgpt.com/codex):** Environments ← בחר או צור סביבה לריפו `cfir94/moreh-derech`.
   - Setup script: `npm ci`
   - Internet access: "On" עבור npm. (לא חובה מעבר לזה.)
2. **כדי להפעיל משימה:** פתח משימה חדשה ב-Codex עם הטקסט הבא, בדיוק:

   ```
   קרא את docs/team/PROTOCOL.md ואת docs/team/BOARD.md.
   קח את המשימה הבאה שמסומנת "Codex" ו-"ready" (או את המשימה <ID> אם ציינתי),
   קרא את docs/team/codex/<ID>.md ובצע אותה לפי הפרוטוקול. פתח PR.
   ```

3. **לא צריך לבחור משימה בעצמך.** הלוח אומר מה הבא בתור. אם אין משימה פנויה ל-Codex, הוא יגיד זאת ולא יעשה כלום.
4. **אפשר להריץ כמה משימות Codex במקביל**, כל עוד הן מסומנות ready ובאזורי קבצים שונים. הלוח מבטיח את זה.
5. **הפעלה מ-GitHub:** אם התקנת את Codex ב-GitHub, אפשר גם לכתוב בתגובה ל-PR `@codex <הוראה>`. אני (Claude) עשוי להשתמש בזה כדי לבקש מ-Codex תיקונים ב-PR שלו.

## "משימות מתוזמנות" ל-Codex

ל-Codex אין תזמון מובנה. התחליף: **ChatGPT Tasks** (ראו `docs/team/chatgpt/SETUP.md`) מזכיר לך פעם ביום לבדוק אם יש משימות Codex ב-ready. ההפעלה עצמה לוקחת כמה שניות: מדביקים את הטקסט שלמעלה.
