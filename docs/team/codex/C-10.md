## Pages (static export: one route, state in the query string)
`/community/` is a single client page. `?f=<slug>` shows a forum, `?f=<slug>&t=<id>` a thread. Use `useSearchParams` inside `<Suspense>`, and push the URL with `router.push` so Back works.

1. **Home of the community** (`/community/`): one card per forum from `myForums()`:
   - title, description, "N חדשות" badge when `unread > 0`, last activity ("לפני 3 שעות").
   - Not a member: if `request === "pending"`, show "הבקשה ממתינה לאישור"; if `"banned"`, show nothing clickable; otherwise a "בקשה להצטרף" button (`requestJoin`).
   - Guest (not logged in): a short line and a link to `/login/`.
2. **Forum** (`?f=slug`): list of threads (`threads(id)`): pinned first with a 📌, title, author_name, reply count, last activity. A big "נושא חדש" button only when `can_open`. Opening the forum calls `markRead(id)`.
   - For `kind === "board"` (פרסומים) the list is styled as announcement cards (title, first 200 chars of body, date), not a chat.
3. **Thread** (`?f=slug&t=id`): the opening post, then replies (`thread(id)`) in chronological order, each with author_name and time; a reply box at the bottom (textarea + "שליחה"), sending with `reply()`, then refresh. Links in post text become clickable (`https?://…` only; render as text otherwise; never `dangerouslySetInnerHTML`). Preserve line breaks.
4. **New thread form**: title (3–140 chars) + body; after `openThread` go to the new thread.
5. **Admin controls** (only when `isAdmin()` from `src/lib/manualAccess.ts` is true): on each thread/post, small "הסתרה"/"החזרה" (`adminHide`), on threads "הצמדה" (`adminPin`). Hidden items show to the admin greyed with "מוסתר".
