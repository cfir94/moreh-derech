# CX-01 — סקירת בריאות קוד (דוח בלבד)

**מי:** Codex · **ענף:** `codex/CX-01-health-report` · **היקף:** יוצרים **רק** את `docs/team/reports/CX-01.md`. **אין לשנות שום קובץ אחר.**

## הפרומפט

> אתה מפתח בכיר שעושה סקירת בריאות לקוד של אתר Next.js 16 סטטי (output: export) בעברית.
> קרא קודם את `CLAUDE.md` ואת `docs/team/PROTOCOL.md`.
> המטרה: **דוח** שמפרט בעיות אמיתיות ומדורגות, כדי ש-Claude יחלק אותן למשימות תיקון. **אל תתקן כלום.**
>
> הרץ ותעד את התוצאות (מספרים, ולא רק "עבר" או "נכשל"):
> 1. `npm ci && npm run lint`: מספר שגיאות ואזהרות, ו-10 הקבצים עם הכי הרבה.
> 2. `npx tsc --noEmit`: שגיאות טיפוסים.
> 3. `npm run test:regressions`, וגם כל `tests/*.test.mjs` שלא נכלל בו (`node --import ./tests/register-ts.mjs --test tests/<file>`). אילו נכשלים, ולמה.
> 4. `npm run build`: עובר? כמה זמן? גודל `out/` בסך הכול, ו-10 ה-chunks הגדולים ב-`out/_next/static/chunks`. אילו דפים טוענים JS גדול במיוחד בטעינה ראשונה?
> 5. **קבצים גדולים בריפו:** כל קובץ מעל 2MB ב-`public/` וב-`src/`.
> 6. **קוד מת:** קבצים ב-`src/` שאף אחד לא מייבא (חיפוש import), ותלויות ב-`package.json` שלא בשימוש.
> 7. **נגישות בסיסית:** חפש `<img` בלי `alt`, כפתורים בלי טקסט או `aria-label`, ו-`onClick` על `div` בלי `role`/`tabIndex`. תן מספרים ו-10 דוגמאות עם `file:line`.
> 8. **הפרות מוסכמות** מתוך `CLAUDE.md`: צבעי Tailwind גולמיים (`text-neutral-`, `bg-white`, `text-gray-` וכו'), נתיבי assets בלי `withBasePath`, ו-`localStorage` שנקרא בלי `useSyncExternalStore`. מספרים ודוגמאות.
> 9. **אבטחה:** סודות שנכנסו לקוד (מפתחות API פרטיים, לא anon key ציבורי), `dangerouslySetInnerHTML` עם קלט משתמש, ו-`eval`.
> 10. **`history-talk/`:** `npm ci && npm run typecheck && npm test`.
>
> **מבנה הדוח** (`docs/team/reports/CX-01.md`):
> - `## סיכום`: 5 שורות.
> - `## ממצאים`: טבלה עם עמודות חומרה (קריטי/גבוה/בינוני/נמוך), תחום, תיאור, דוגמה `file:line`, והצעת תיקון במשפט אחד.
> - `## מדדים`: התוצאות הגולמיות של סעיפים 1–5.
> - `## הצעה לחלוקה למשימות`: קבוצות תיקון שכל אחת נוגעת באזור קבצים נפרד, כדי שיהיה אפשר לעבוד עליהן במקביל.
