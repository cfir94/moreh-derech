# CX-02 — SEO: כותרות, תיאורים, Open Graph, sitemap ו-robots

**מי:** Codex · **ענף:** `codex/CX-02-seo` · **תלוי:** אין

**היקף (רק אלה):** שדות `metadata` ב-`src/app/**/page.tsx` ו-`src/app/**/layout.tsx`. קבצים חדשים: `src/app/sitemap.ts`, `src/app/robots.ts`, `src/lib/seo.ts`. **לא לשנות שום לוגיקה, רכיב או תוכן אחר.**

## הפרומפט

> קרא קודם את `CLAUDE.md`, את `AGENTS.md` ואת `docs/team/PROTOCOL.md`. האתר הוא Next.js 16 עם `output: "export"`. קרא את `node_modules/next/dist/docs/` לפני שאתה משתמש ב-API של metadata/sitemap, כי זו גרסה חדשה.
>
> המטרה: שכל דף ציבורי יופיע נכון בגוגל ובשיתוף בוואטסאפ ובפייסבוק. הדומיין הקנוני: `https://moreyderech.com`. שם האתר: "אבן דרך למורי דרך".
>
> 1. `src/lib/seo.ts`: `SITE_URL = "https://moreyderech.com"` ו-`SITE_NAME`, ופונקציה `pageMeta({ title, description, path })` שמחזירה `Metadata` עם `title`, `description`, `alternates.canonical`, `openGraph` (locale `he_IL`, `type: website`, `siteName`, `images: [/marketing/og.jpg]`) ו-`twitter: { card: "summary_large_image" }`.
> 2. ב-`src/app/layout.tsx`: `metadataBase: new URL(SITE_URL)` ו-`title.template: "%s — אבן דרך למורי דרך"`. **רק את ה-metadata. לא לגעת ב-JSX.**
> 3. לכל דף ברשימה הבאה: `title` קצר (עד 50 תווים) ו-`description` (120–155 תווים) **בעברית, שמתארים מה באמת יש בדף.** בדוק בקוד של הדף, ואל תמציא: `/`, `/quizzes`, `/exams`, `/timelines`, `/games`, `/map`, `/map/learn`, `/resources`, `/guide-reports`, `/videos`, `/pricing`, `/games/crossword`, `/games/who-am-i`, `/games/jerusalem-robes`, `/timelines/history-atlas`, `/timelines/roman`, `/timelines/byzantine`, `/timelines/classical-architecture`. דף שהוא `"use client"` לא יכול לייצא metadata. במקרה כזה הוסף `layout.tsx` דק באותה תיקייה, שמייצא רק metadata ומחזיר `children`.
> 4. `src/app/sitemap.ts`: כל הנתיבים מסעיף 3, וגם `/quizzes/<slug>` ו-`/exams/<slug>` מתוך מקורות הנתונים הקיימים (`src/data/quizzes/index.ts`, `src/data/exams/index.ts`), בלי לשנות אותם. **לא לכלול** `/me`, `/login`, `/notebooks`, `/legal/*`, `/timelines/classical-architecture/v1`.
> 5. `src/app/robots.ts`: לאפשר הכול, חוץ מ-`/me/` ו-`/login/`, עם הפניה ל-sitemap.
> 6. ודא ש-`npm run build` עובר, ושנוצרו `out/sitemap.xml` ו-`out/robots.txt`. הרץ `npm run lint` על הקבצים ששינית, ו-`npm run test:regressions`.
