# LA-51 — אינדקס עזרי הלמידה בקבוצות

## מה נעשה

- האינדקס ב־`/timelines` חולק לחמש קבוצות ברורות, עם כותרת ושורת הסבר לכל קבוצה.
- כל הכרטיסים והקבוצות הועברו למערך נתונים אחד ב־`src/data/learning-aids.ts`.
- נוספו מגדיר הצמחים, צירי הברית החדשה ומצרים–כנען, מפת הלמידה ותכנון המסלול.
- שורות היכולת הותאמו לכל עזר, והספירות הקיימות נגזרות מהנתונים.
- נוסף מבחן דפדפן לדסקטופ ולטלפון, כולל קישורים ורוחב 360 פיקסלים.

## מה נבדק

- `npm run lint` — עבר.
- `npx tsc --noEmit` — עבר.
- `npm run test:regressions` — עברו 127 בדיקות ב־Node 22.
- `npm run build` — עבר; נוצרו 118 דפים סטטיים.

## מה לא נעשה

- מבחן Playwright נכתב אך לא הורץ בסביבת Codex, לפי הנחיית המשימה.
- נתיבי הדגמה וגרסאות ישנות שאינם מקושרים (`shell-demo`, `history`, `classic`, `v1`) לא נוספו לאינדקס.
- לא ניתן היה למשוך את `main`: לסביבת העבודה אין remote בשם `origin`. העבודה מבוססת על `066262d`, שכבר כולל את LA-41 ואת LA-60.
