# N-03 — קישור למקור לכל תשובת תשבץ

## מה נעשה

- נוספה מתחת ללוח רשימת "תשובות והסברים", שמציגה רק מילים שכבר נפתרו, נבדקו או נחשפו.
- מילים שנבדקו כשגויות או שנחשפו עולות לראש הרשימה ומסומנות "כדאי לחזור".
- כל שורה כוללת תשובה, הגדרה, משפט ההקשר, שם מאגר המידע וקישור ישיר למחברת NotebookLM בחלון חדש.
- נוספו בדיקות דפדפן לחשיפה ההדרגתית, לסדר, לסימון, לקישור וליעד מגע של 44 פיקסלים בטלפון.

## מה לא נעשה

- לא נערכו מאגר המילים, חתימות התשבצים או תוכן המחברות.
- מצב "נבדק כשגוי" נשמר במהלך המשחק הפתוח; לאחר טעינה מחדש של תשבץ שטרם הושלם, הרשימה נבנית מחדש מן המילים שנפתרו או נחשפו. בתשבץ שהושלם כל המילים מוצגות.
- בדיקת Playwright נכתבה אך מיועדת להרצה בידי Claude לפי פרוטוקול המשימה.

## בדיקות

- `npm run lint` — עבר.
- `npx tsc --noEmit` — עבר לאחר שה-build יצר את טיפוסי Next.js; לפני ה-build חסרו טיפוסי `PageProps` ו־`LayoutProps` שנוצרים אוטומטית.
- `npm run test:regressions` — עברו 131 בדיקות.
- `npm run build` — עבר, כולל export סטטי של 119 עמודים.
- `node --import ./tests/register-ts.mjs tests/crossword-ui.mjs` — לא רץ בסביבה זו כי חבילת `playwright` אינה מותקנת. הבדיקה הורחבה וממתינה להרצת Claude.
- לא צולם צילום מסך מאותה מגבלת Playwright.
