# CX-02 — SEO: metadata, sitemap ו-robots

## מה נעשה

- נוסף helper מרכזי ל-metadata עם כתובת קנונית, Open Graph וכרטיס Twitter.
- נוסף metadata ייחודי לכל 18 הדפים הציבוריים שנקבעו במשימה.
- נוספו sitemap דינמי לכל הדפים הציבוריים ולכל דפי השאלונים והמבחנים, ו-robots שמחריג כניסה ואזור אישי.

## בדיקות

- `npm run lint` — נכשל במגבלת סביבה של formatter על קובצי bundle גדולים תחת `public/embeds` (`RangeError: Invalid string length`).
- `npx eslint <כל קובצי המקור ששונו>` — קובצי המקור החדשים ושינויי ה-metadata עברו; ב-`src/app/resources/page.tsx` נשארו 3 שגיאות `react/no-unescaped-entities` קיימות ב-JSX שלא שונה, ולכן לא תוקנו מחוץ להיקף.
- `npx tsc --noEmit` — נכשל בבעיות קיימות: globals חסרים של `PageProps`/`LayoutProps` והקובץ החסר `src/assets/brand-icon.png`.
- `npm run test:regressions` — עברו 42 בדיקות.
- `NEXT_PUBLIC_BASE_PATH='' npm run build` — הגיע לבניית production אך נכשל כי הסביבה לא הצליחה להוריד את Heebo ואת Frank Ruhl Libre מ-Google Fonts; לכן לא ניתן היה לאמת את קובצי `out` כאן.

## לא נעשה

- לא שונתה לוגיקה, JSX או תוכן דפים.
- לא נוספו ל-sitemap דפים פרטיים, משפטיים או גרסת v1 של סטודיו האדריכלות.
