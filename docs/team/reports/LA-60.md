# LA-60 — מגדיר צמחים

## מה נעשה

- נוסף מגדיר אינטראקטיבי ב־`/timelines/plants-guide`: סינון לפי קבוצה, עונה וצורת חיים, חיפוש חופשי ואריחי תוצאות.
- נוסף כרטיס צמח בקישור עמוק `#plant-<id>`, עם סימן מזהה ראשון, כל שדות השטח, קישורים לצמחים דומים ותמונות מאושרות בלבד כאשר קובץ התמונות קיים.
- נוסף גלגל של 12 חודשים ומפרש טהור לטקסטי העונה, וכן הדרכת ביקור ראשון.
- נוספה בדיקת יחידה שעוברת על כל 40 הצמחים. נוסף קובץ UI ש-Claude יוכל להרחיב ולהריץ עם Playwright.

## טקסטי עונה שלא ניתן לשייך לחודש בלי לנחש

- אשל: `פריחה ורודה או לבנה`
- שיטה סלילנית: `פריחה צהובה; תרמילים מפותלים`

## בדיקות

- `npm run lint` — עבר.
- `npx tsc --noEmit` — עבר לאחר שה־build יצר את טיפוסי Next.
- `npm run test:regressions` — עבר, 127 בדיקות.
- `npm run build` — עבר, כולל יצירה סטטית של `/timelines/plants-guide`.
- בדיקת המפרש הטהור עברה לפני הרחבת הקובץ לתרחיש Playwright; תרחיש ה־UI המלא לא הורץ לפי ההנחיה.
- `impeccable detect` — לא רץ: מנוע הסקיל אינו מותקן והורדתו מ־GitHub נכשלה בסביבה.

## לא נעשה

- לא נערכו נתוני הצמחים ולא רכיבי משחק הצמחים.
- לא הורץ Playwright, לפי הוראות המשימה.
- `git pull origin main` לא היה אפשרי: לסביבת העבודה אין remote בשם `origin`; העבודה התחילה מה־commit המקומי `400307d`, שהוא `main` שסופק.
