# LA-01 — מעטפת משותפת לעזרי למידה

## מה בוצע

- נוספו רכיבי מעטפת מטופסים לעזרי למידה: כותרת, מסילת לשוניות, חיפוש, כרטיס סיכום, תמונה עם קרדיט ותרגול רב־ברירה.
- הלשונית הפעילה מסונכרנת ל־hash באמצעות `useSyncExternalStore` ו־`history.replaceState`; resolver אופציונלי מאפשר להפנות hash של כרטיס ללשונית המתאימה.
- התרגול מערבב אפשרויות, מציג משוב חזותי, שומר תוצאה דרך `recordAttempt` ומקדים טעויות בסבב הבא.
- נוסף דף הדגמה פנימי בנתיב `/timelines/shell-demo/`, עם metadata של noindex ורכיב לקוח דק לאינטראקציות.
- נוסף מבחן UI ל־export הסטטי, בדסקטופ ובטלפון.
- לא נוספו תלויות ולא שונו קבצים קיימים.

## פקודות ותוצאות

- `find .. -name AGENTS.md -print` וקריאת `AGENTS.md` — הצליחו; הוראות הריפו נקראו.
- `cat docs/team/PROTOCOL.md`, `cat docs/team/BOARD.md`, `cat CLAUDE.md`, `cat docs/learning-aids/DESIGN.md`, `cat docs/team/codex/LA-01.md` — הצליחו; מסמכי העבודה והמפרט נקראו במלואם.
- `git switch -c codex/LA-01-shell` — הצליח; הענף נוצר מה־HEAD שסופק כ־`main`.
- `source "$HOME/.nvm/nvm.sh" && nvm use 22 && npm run lint` — הריצה הראשונה מצאה קריאת ref בזמן render ב־`PracticeDeck`; התוצאה הועברה ל־state.
- `source "$HOME/.nvm/nvm.sh" && nvm use 22 >/dev/null && npm run lint` — הצליח לאחר התיקון.
- `source "$HOME/.nvm/nvm.sh" && nvm use 22 >/dev/null && npx tsc --noEmit` — הריצה הראשונה נכשלה מפני שטיפוסי Next המיוצרים (`PageProps` ו־`LayoutProps`) טרם נוצרו.
- `source "$HOME/.nvm/nvm.sh" && nvm use 22 >/dev/null && npm run test:regressions` — הצליח: 121/121 בדיקות עברו.
- `source "$HOME/.nvm/nvm.sh" && nvm use 22 >/dev/null && npm run build` — הצליח: 114 דפים סטטיים נוצרו, ובהם `/timelines/shell-demo`.
- `source "$HOME/.nvm/nvm.sh" && nvm use 22 >/dev/null && npx tsc --noEmit` — הצליח לאחר יצירת טיפוסי Next ב־build.
- `source "$HOME/.nvm/nvm.sh" && nvm use 22 >/dev/null && node tests/learning-aid-shell-ui.mjs` — לא רץ: החבילה האופציונלית `@playwright/test` אינה מותקנת בסביבה.
- `git add -N .`, `git diff --check` ובדיקת classes עם `rg` — הצליחו; כל הקבצים החדשים נכללו ב־diff, לא נמצאו שגיאות whitespace, צבעים גולמיים או `shadow-glow`.
- `git add … && git commit -m "[LA-01] Add learning-aid shell components"` — הצליח; השינויים נשמרו ב־commit בענף המשימה.
- `git diff main` — הצליח לאחר יצירת reference מקומי ל־HEAD שסופק כבסיס `main`; הופק ה־diff המלא למסירה.

## מה לא בוצע

- לא שונו קבצים קיימים ולא נוספו תלויות.
- לא בוצע merge ל־`main`.
- מבחן ה־UI וצילומי המסך לא הורצו בפועל מפני שאין בסביבה Playwright; קובץ הבדיקה מוכן להרצה בסביבת CI שמתקינה אותו.
