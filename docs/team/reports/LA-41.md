# LA-41 — צירי הברית החדשה ומצרים–כנען

## מה נעשה

- שני ה־iframe בדפים הראשיים הוחלפו בעמודים מקומיים הבנויים מרכיבי מעטפת עזרי הלמידה.
- ציר הברית החדשה חולק לחמש הלשוניות שבנתונים. כל 40 האירועים מוצגים בסדר הנתונים, עם הכותרת, המקור, הגוף, הציטוט וכל המקטעים ללא שינוי.
- ציר מצרים–כנען חולק לפי קבוצות `kind` שבנתונים, כולל כל שבעת האירועים, ההסתייגויות והדגשי המבחן.
- נוספו חיפוש, קישורי hash ישירים לכרטיסים, ותרגול מקומי ששומר התקדמות דרך `PracticeDeck`.
- נוספו הדרכות ביקור ראשון לשני העזרים.
- הגרסאות המוטמעות הישנות נשמרו בנתיבי `/classic`, עם `noindex` וללא קישור מהעמודים החדשים.
- נוספה בדיקת Playwright לדסקטופ ולטלפון. היא משווה את תוכן הברית החדשה ישירות לנתונים, בודקת קישורים עמוקים, תרגול, היעדר גלילה אופקית ועמודי classic.

## בדיקות

- `git fetch origin main && git rebase origin/main` — לא רץ: לעותק העבודה אין remote בשם `origin`; העבודה התחילה ישירות ב־`7262ec9`, ה־SHA של המפרט שנמסר.
- `npm run lint` — עבר ללא שגיאות.
- `npx tsc --noEmit` — עבר.
- `npm run test:regressions` — עברו 127 בדיקות.
- `npm run build` — עבר; נבנו 116 עמודים סטטיים, כולל שני העמודים ושני נתיבי classic.
- `node tests/biblical-egypt-ui.mjs` — לא הורץ; לפי מפרט המשימה Claude יריץ Playwright.
- `git diff --check main` — עבר ללא פלט.
