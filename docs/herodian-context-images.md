# Images in the local-rulers context note

The expandable note “ואיפה הורדוס, אנטיפס ואגריפס?” now includes three locally hosted images with role labels, the same Roman relationships as the original text, source/license links and image enlargement. These figures remain contextual rulers; the existing 36-person Roman dataset and its practice/filter behavior are unchanged.

- Herod the Great: HerodtheGreat2.jpg, a late imagined engraving (creator unknown, public domain), explicitly labelled as later art.
- Antipas: James Tissot, Herod (1886–1894), Brooklyn Museum 00.159.130. The museum identifies him as Antipas: https://opencollection.brooklynmuseum.org/objects/4506 . This resolves the mistaken “Herod the Great” text in the Commons image description. Explicitly labelled as later art.
- Agrippa I: a contemporary coin portrait, Caesarea, 42–43 CE. Photograph by Classical Numismatic Group, CC BY-SA 3.0. Not Marcus Agrippa, Agrippa II or Caligula.

All three downloaded WebP images were visually reviewed. Metadata and original image descriptions are retained in src/data/herodian-companions.ts; the Antipas description is corrected there with the museum attribution. Images were resized and converted to WebP.

The section name is now “עזרי למידה” in navigation, home, section heading, breadcrumbs, back links and site-search helper text. Descriptions reflect the broader collection of timelines, comparison tables, memory tools and models. Existing /timelines paths, identities and specific historical timeline titles are retained.

The browser test opens the note and requires successful decoding of all three images, checks enlargement links and the renamed navigation/heading, alongside existing portrait/filter/practice coverage. Two pre-existing checks were aligned with the previous coin-portrait revision: Varus is a contemporary coin rather than a late engraving, and the original Livius source is accepted alongside Commons.
